## Observações
- A cidade dos cenários é claramente o **Rio de Janeiro** (Cristo, Pão de Açúcar, Metrô RJ), enquanto o key visual mostra Tóquio. A definir pela bíblia.
- Corporação antagonista: **ORDECON**.
- Cenários estão em 1024×572 — para vídeo 1080p conviria uma versão em maior resolução.
- Inconsistências de design: na comparação de alturas o protagonista tem detalhes verde-limão (no model sheet são magenta/ciano) e a hacker usa boné e um rabo só; no key visual o veterano não tem o olho implantado.
